# 把识字小助手新加的汉字自动填进你的 Google 表格

**效果**：你在 App 里加的汉字，每周六、周日晚上会自动出现在你表格里**对应孩子的标签页、对应那一周那一行的 B ～ K 列**里（一周最多同步两次；想马上看到，随时点菜单“立即同步”）。

**它只做这一件事，而且很“轻”**：

- 只往 B ～ K 里的**空格**填字，**不覆盖**任何已有内容（包括你手动录入的字）。
- 你在 App 里**删掉**的字，下次同步会把表格里对应的那一格**清掉**（让表格和 App 保持一致，见下面“删除是怎么同步的”）。
  但你**手动录入、App 里本来就没有**的字，永远不动。
- **不碰 A 列和 L 列**，也不碰公式、格式、条件格式——你表格自己的“自动生成周标签、累计字数、重复检测变色”照常工作。
- 这一周这一行里已经有的字不会重复填；重复运行也不会重复填。
- 只读 GitHub，不会改动 App 里的任何数据。App 本身不用改，也不需要 Google 授权登录。

**它怎么知道填到哪一行**：看这个孩子标签页 **A 列里已经有的“第N周-日期”**（例如 `第3周-2026-11-08`），
按日期和 App 里的周对上。A 列还是空的下一周（你的公式要等 B～K 有字才生成），就按“每周一行”顺着往下推，
所以新的一周的字会填到最后一行下面的那一行。

**对表格的要求**（你现在的表格已经满足）：

- 每个孩子一个标签页，**标签页的名字和 App 里孩子的名字一样**（Dory、Leo、Antoine）。
- 一行一周，周按每周日对齐（和 App 一致）；A 列是周标签，B ～ K 是这一周的 10 个字。

> **请在电脑上设置**（Google 表格的脚本编辑器在 iPad 上不好用）。设置好以后，iPad 上只管用 App，表格会自己更新。
> 整个过程大约 10 分钟，只做一次。

## 第 0 步：拿到脚本

脚本就是这个文件：`docs/google-sheet-sync/sync.gs`，有两种方式拿到：

- **方式 A（最简单）**：在 App 里 **设置 → 同步到 Google 表格 → 复制同步脚本**，然后到第 3 步粘贴。
  （在电脑上用网页版打开 App 做这一步最方便。）
- **方式 B**：在 GitHub 上打开 `LearningChinese` 仓库 → `docs` → `google-sheet-sync` → `sync.gs`，
  点右上角的“复制原始内容”按钮（两个方框叠在一起的图标），或者点 **Raw** 后 `Ctrl+A` 全选、`Ctrl+C` 复制。

先别关，后面第 3 步要粘贴。

## 第 1 步：（建议）先备份一份表格

脚本只往空格里填字，不会删改你的内容，但留一份副本总是更放心：

1. 打开你的 Google 表格。
2. 左上角 **文件 → 创建副本**，名字随便，点确定。

## 第 2 步：建一个“只读”的 GitHub 令牌（专门给表格用）

这是**另一个令牌**，权限比 App 用的小：只能读，不能写。**不要**把 App 的令牌用在这里。

1. 打开 https://github.com/settings/personal-access-tokens/new
2. **Token name** 填 `表格同步（只读）`。
3. **Expiration** 选 1 年（到期后重新生成一个，见最后的“常见问题”）。
4. **Repository access** 选 **Only select repositories**，只选你的数据仓库（`LearningData`）。
5. 点 **Repository permissions** 旁边的 **Add permissions**，勾选 **Contents**，
   然后把右边的权限改成 **Read-only**（只读）。（Metadata 会自动加上，是只读的，不用管。）
6. 点最下面的 **Generate token**。
7. 复制那串 `github_pat_…`，先粘贴到一个临时的记事本里。页面关掉后就看不到了。

## 第 3 步：把脚本放进 Google 表格

1. 打开你的 Google 表格，点上方菜单 **扩展程序 → Apps Script**。会打开一个新页面（脚本编辑器）。
   （如果你的表格里已经有别的脚本，可以新建一个文件放它，或者直接在同一个项目里加；不要删掉原来的。）
2. 左上角点“无标题的项目”，改名为 `识字助手同步`，点确定。
3. 编辑区里原来有一段 `function myFunction() { }`：点一下编辑区，按 `Ctrl+A` 全选，按 `Delete` 删掉。
4. 按 `Ctrl+V` 粘贴刚才复制的整段脚本。
5. 点上方的 **保存**（软盘图标，或按 `Ctrl+S`）。
6. 回到你的表格页面，按 `F5` **刷新页面**。等几秒，菜单栏最右边（“帮助”后面）会出现 **识字助手**。

> 没有出现“识字助手”菜单？再刷新一次，等 10 秒；还不行，看最后的“常见问题”。

## 第 4 步：连接 GitHub 并同步

### 4.1 设置连接

1. 点菜单 **识字助手 → 1. 设置 GitHub 连接**。
2. 第一次会弹出 **需要授权**：点 **继续**。
3. 选择你的 Google 账号。
4. 看到 **Google 尚未验证此应用**：这是正常的（脚本是你自己的，没有提交给 Google 审核）。
   点左下角的 **高级**，再点 **转至“识字助手同步”（不安全）**。
5. 页面列出脚本要的权限（查看和管理这个表格、连接外部服务、定时运行），点 **允许**。
6. 授权完成后，可能需要**再点一次菜单** **识字助手 → 1. 设置 GitHub 连接**。
7. 第一个输入框填你的仓库，格式是 **你的 GitHub 用户名/仓库名**，例如 `zhangsan/LearningData`，点确定。
8. 第二个输入框粘贴第 2 步的令牌（`github_pat_…`），点确定。
9. 看到 **连接成功：找到 3 个孩子：Dory、Leo、Antoine** 就对了。

### 4.2 立即同步一次

1. 点菜单 **识字助手 → 2. 立即同步**。
2. 看到 **同步完成**，提示里会写每个孩子**新填入了几个字、已有几个字**。
   第一次同步时，你表格里已经有的字都会算“已有”，只有表格里还没有的字才会被填进去。
3. 看一下你的表格：新填入的字出现在对应那一周的空格里；你的 A、L 列会按你自己的公式自动更新。
   表格里还多了一个 **同步状态** 标签页（放在所有标签页的最右边，记录最后同步的时间和结果），可以把它隐藏起来（右键标签页 → 隐藏）。
   （如果你用的是旧版脚本，这个标签页可能被放在了中间：把它拖到最右边，或者右键删除，下次同步会自动重新建在最右边。）

### 4.3 开启自动同步

1. 点菜单 **识字助手 → 3. 开启自动同步（周六、周日各一次）**。
2. 如果又弹出授权，再点一遍 **允许**。
3. 看到 **自动同步已开启**。

完成。以后每周**周六、周日的晚上 8 点左右**（按这份表格的时区），表格会自动同步一次，一周最多两次。
想马上看到，点 **识字助手 → 2. 立即同步**。

**怎么知道自动同步开着没有：**

- 菜单 **识字助手 → 查看自动同步是否开启**：会弹出一个窗口，写着“已开启”（有几个定时器、每周几几点）或“没有开启”，并告诉你最近一次同步的时间和结果。
- 也可以看 **扩展程序 → Apps Script** 左边的“触发器”（闹钟图标）：开启后会有两条函数名叫 `syncAuto` 的定时器（周六、周日各一条）。
- 每次同步（不管是手动还是自动）之后，“同步状态”标签页的第一行都会更新“最后同步时间”。

## 删除是怎么同步的

表格当备份，App 里删了的字，表格里也要删，不然累计字数对不上。做法很谨慎：

- 脚本每次同步后，会在这份表格的**脚本属性**里记下“App 当时有哪些字”（每周一条，很小）。
- 下次同步时，只清掉“**上次 App 有、这次 App 没有了**”的字（你在 App 里用管理模式删掉的，或者换到别的周去了的），
  而且只清那一格里**正好是这个字**的格子。
- 你手动录入、App 里本来就没有的字：不在记录里，**永远不会被清**。
- 如果你在表格里把某个字手动改成了别的，App 再删原来的字时，那一格因为已经不是这个字了，**不会被清**。
- **两道保险**：① GitHub 上读不到这个孩子的数据时（出错了而不是你删了），一律不清；② 一次要清的字超过 **30** 个时，
  不清，并在“同步状态”里写明原因（防止出问题时把表格清空）。确认没问题后，可以在 Apps Script 的
  **项目设置 → 脚本属性** 里添加 `MAX_DELETES`，值填一个更大的数（比如 `50`），下次同步就会清。
- **第一次用这个版本时**，脚本只是建立记录，不会清任何东西。在这之前你在 App 里删掉的字，请在表格里手动清一次。

## 成语标签页：自动在 B 列打勾

你的“成语”标签页（A 列 = 成语，B 列 = 打勾的格子，C 列 = 表格自己算的数量）也会同步：

- App 里每周会从“成语库”随机选 6 个成语给下一周。同步时，脚本把 **App 里已经分配到某一周的成语**，在 B 列对应的格子 **打上勾**。
- 只会 **打勾**：不会取消任何已有的勾；只写 B 列的格子；A 列（你锁定的成语）和 C 列（计算）一律不碰；重复同步不会重复写。
- **E 列放故事（以 App 为准）：** App 是主，表格只是备份。同步时，App 里有故事的成语，E 格是空的就写进去；E 格里是别的内容，就改成 App 里的故事，所以你在 App 里改了故事，下次同步表格里的备份也跟着变。App 里没有故事的成语，E 格不会被清空。一次最多改写 50 个有内容的 E 格，再多就不改，并在“同步状态”里提醒。表格里直接改的故事，不会回到 App，也会在下次同步时被 App 的版本换掉。
- **D 列写学习的周：** 同步时，App 里已分配到周的成语，会在 D 列写上学习的周，写法和孩子标签页的 A 列一样，例如 `第4周-2026-11-15`。D 格是空的、或者里面是一个周标签但周不一样时才写；你自己在 D 列写的别的内容不会动。
- **重新导入会冲掉现有的周：** 在 App 里再导入这张表时，App 里现有的各周成语会被 **冲掉，按表格重新安排**：D 列写了周的成语回到那一周，没写周的已勾选成语按表格顺序，每周 6 个，分配到已开始的几周和下一周。预览里会先提醒你。
- 你在 App 里 **手动添加** 的、表格里还没有的新成语，会 **加到 A 列最后一个成语的下面**，B 列同时放一个勾选框并打勾；C 列留给你表格自己的公式，不碰。一次最多加 30 个，再多就不加并在“同步状态”里提醒。
- **需要取消 A 列的编辑限制吗？** 脚本是以你这个 Google 账号的身份运行的。如果你的限制是“只有我（所有者）能编辑”或“编辑时只提醒”，脚本可以直接写，不用取消。如果限制里没有包含你授权脚本的那个账号，同步状态里会出现权限错误，这时请把这个账号加进允许编辑的名单（不必完全取消限制）。这一点我没法在你的真实表格上测试。
- 表格里没有叫“成语”的标签页时，这一步自动跳过，其他同步照常。
- 第一次要先在 App 里导入这张表（设置 → 从 Excel 导入）：A 列是成语、B 列是勾，App 会把已打勾的按表格顺序分配到已经开始的几周和下一周（每周 6 个），其余的留在成语库里，之后每周自动随机选。

## 日常使用

- 在 App 里加字就行。你仍然可以在表格里手动录字，两边不冲突：脚本只补表格里**没有**的字，不会动你写的。
- 想确认它在自动运行：周末过后看 **同步状态** 标签页里的“最后同步时间”，应该是周六或周日晚上。
  也可以在 Apps Script 页面左边点闹钟图标 **触发器**，应该看到两条 `syncAuto`（周六、周日）。
- **重复检测**还是你表格自己的：如果某个字在表格里别的周也有，你的条件格式会照常变色提示，脚本不会替你判断。

## 需要知道的几件事

| 情况 | 会怎样 |
|---|---|
| 你在 App 里用“管理模式”**删掉**了一个字 | 下次同步，表格里对应那一格会被清掉（只清 App 知道的字，见上面“删除是怎么同步的”）|
| 表格里有你手动录的字，App 里没有 | 原样保留，永远不会被清 |
| 这一周这一行的 B～K **已经满了 10 个**，App 里还有新字 | 放不下的字不会硬塞：状态里会写“第 N 行（日期）B～K 已经满了，放不下：某某字” |
| App 里有某个孩子，表格里**没有同名的标签页** | 这个孩子会被跳过，不会自己新建标签页；状态里写明了，请把标签页改成孩子的名字 |
| App 里某一周在表格**第一行之前** | 表格里没有那一行，跳过，状态里说明 |
| 某一行 A 列的周标签和 App 里的周对不上 | 不填这一行，状态里说明是哪一行 |
| 新的一周在表格**最后一行的下面** | 自动在下面加行再填。如果你的 A、L 公式需要向下拖，请自己把公式拖到新行 |
| App 里改了孩子的名字 | 表格里要把标签页也改成新名字，否则会被当作“没有标签页”跳过 |
| 成语 | **不同步**（你表格里的“成语”标签页不会被动）|

## 常见问题

**菜单里没有“识字助手”**
刷新页面并等 10 秒。还没有的话，回到 Apps Script 页面，确认代码已保存，并且里面有 `function onOpen()`（说明粘贴完整了）。

**提示：GitHub 说令牌无效或已过期（401）**
令牌复制不全，或已过期。重新生成一个令牌（第 2 步），再点 **1. 设置 GitHub 连接** 填一次。

**提示：GitHub 拒绝访问（403）**
令牌没有这个仓库的读取权限。回到令牌设置页，确认 **Repository access** 选了你的数据仓库，
**Contents** 是 Read-only。

**提示：仓库里还没有 kids.json**
数据仓库里还没有数据。先在 App 里添加孩子并录入汉字（或导入表格），再同步。

**想改自动同步的日子或时间**
在 Apps Script 里找到脚本开头的这两行：

```
var SYNC_DAYS = ['SATURDAY', 'SUNDAY'];
var SYNC_HOUR = 20;
```

- 只想**每周一次**：改成 `var SYNC_DAYS = ['SUNDAY'];`
- 想换别的日子：用英文星期，例如 `['FRIDAY', 'SUNDAY']`（可选 MONDAY 星期一、TUESDAY、WEDNESDAY、THURSDAY、FRIDAY、SATURDAY 星期六、SUNDAY 星期日）。
- 想换时间：`SYNC_HOUR` 填 0 ～ 23 的整数（20 就是晚上 8 点，Google 会在这个小时内的某个时间运行）。时间按这份表格的时区，
  在表格里 **文件 → 设置 → 时区** 可以看和改。

改完点 **保存**，再点菜单 **识字助手 → 3. 开启自动同步**（它会先删掉旧的自动同步，再按新设置重建）。

**从旧版本（每 10 分钟）升级后，自动同步还是每 10 分钟？**
旧的定时器不会自己消失。换上新脚本后，点一次菜单 **识字助手 → 3. 开启自动同步（周六、周日各一次）**，
它会把旧的“每 10 分钟”删掉，换成周六、周日各一次。

**脚本找错了行**
正常情况下脚本按你 A 列里的“第N周-日期”找行。只有当这个孩子的标签页 A 列**一个日期都没有**时（比如全新的空标签页），
才会用 App 里最早的一周当第 1 行。你可以固定这个日期：在 Apps Script 页面左边点齿轮 **项目设置**，拉到 **脚本属性**，
点 **添加脚本属性**，属性填 `FIRST_WEEK`，值填 `2026-10-25`（必须是第 1 行那一周的星期日），保存。

**令牌到期了**
到期后同步会显示 401。重新生成令牌，点 **1. 设置 GitHub 连接** 重新填写即可。

**想完全停掉**
点 **关闭自动同步**；再到 GitHub 的令牌页面把“表格同步（只读）”这个令牌删除。

## 关于安全

- 令牌保存在这份表格的**脚本属性**里，只有能编辑这份表格的人才可能看到。
  **不要把表格的“编辑者”权限给不信任的人**；只给“查看者”是安全的。
- 令牌是**只读**、只对你的数据仓库有效，即使泄露，别人也改不了你的数据；但能读到孩子的学习记录，所以请妥善保管。
- 脚本只做这些事：读取 GitHub；往你表格孩子标签页的空格里填字；清掉你在 App 里删掉的字所在的那一格；写“同步状态”标签页和脚本属性里的记录。
  可以直接打开 `sync.gs` 阅读，没有隐藏的东西。
